# CKBuilder Programme

My development log for learning and building on Nervos CKB.

## What I learned

- Running a local CKB Devnet with OffCKB.
- Building and deploying a CKB contract.
- Transferring CKB and checking transaction state through JSON-RPC.
- Writing data to a Cell and reading it back.
- Creating and rendering a Spore digital object.
- Building, deploying, funding, and unlocking a simple hash-lock Script.
- Checking occupied-capacity requirements before submitting a transaction.
